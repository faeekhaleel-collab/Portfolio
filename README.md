# Faees Mohammed — Portfolio

Certified Management Accountant (CMA-USA) working across finance, audit and procurement.

## What's here

A static site served straight from this repository by GitHub Pages, plus three
working demos of procurement tools:

| Demo | Path |
|---|---|
| Quote Desk — quotation extraction and checking | `demo/quote-desk/quote-desk.html` |
| Procurement Dashboard — PO, debit note and payables reporting | `demo/dashboard/` |
| Fleet Rate Card — paid-rate benchmark | `demo/rate-card/` |

Every figure, company, place and supplier in the demos is invented and generated
for demonstration. No client data appears anywhere in this repository.

## Hosting

Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
`.nojekyll` is present so the `assets/` folders are served unprocessed. All paths
are relative, so the site works at a domain root or at a project subpath.
